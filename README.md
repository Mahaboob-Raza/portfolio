# Mahaboob Raza Portfolio

This is a static portfolio website built with HTML5, CSS3, vanilla JavaScript and Bootstrap 5.3 from CDN.

## Project Structure

- `index.html`
- `css/style.css`
- `js/script.js`
- `assets/images/profile.jpg`
- `assets/images/timetable-preview.jpg`
- `assets/images/resume-ai-preview.jpg`
- `assets/documents/Mahaboob_Raza_Resume.pdf`

## How to use

1. Open `index.html` directly in a browser.
2. Replace the placeholder links in the HTML with your real GitHub, LinkedIn, email and paper URLs.
3. Add your real portrait and project preview images to the `assets/images` folder.
4. Replace the resume placeholder PDF with your actual resume.

## Notes

- The site does not require Node.js or npm.
- Bootstrap is loaded through CDN.
- The layout is responsive and uses subtle scroll reveal animations.
